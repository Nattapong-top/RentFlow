# Architectural Decisions

> บันทึก Architecture Decision Records (ADR) ของโปรเจค
> เพื่อให้ทีมและ AI เข้าใจว่า "ทำไมถึงตัดสินใจแบบนั้น"

---

## Format

```markdown
## ADR-XXX: ชื่อ Decision

**วันที่**: YYYY-MM-DD
**สถานะ**: [Proposed / Accepted / Deprecated / Superseded]

### Context
ปัญหาหรือความต้องการที่ต้องตัดสินใจ

### Decision
สิ่งที่ตัดสินใจทำ

### Consequences
**Pros**: ข้อดี
**Cons**: ข้อเสีย
```
