## Technical Terms (คำศัพท์เทคนิค)

| คำศัพท์ | ความหมาย |
|---------|----------|
| **Value Object** | Object ที่ immutable, เปรียบเทียบด้วย value ไม่ใช่ identity |
| **Entity** | Object ที่มี identity ชัดเจน (เช่น ID) |
| **Domain Service** | Logic ที่ต้องใช้ข้อมูลหลาย object |
| **Repository** | Interface สำหรับ access ข้อมูล |
| **Use Case** | กระบวนการ business ที่ต้องการทำให้สำเร็จ |
