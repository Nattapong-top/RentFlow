# RentFlow Billing Guide & Use Cases

คู่มือการทำงานของระบบคำนวณบิลรายเดือน (Billing & Invoicing Guide) ของ RentFlow

---

## 1. Use Case: การสร้างบิลประจำเดือน (UC-01: Create Monthly Bill)

คลาสหลักคือ `CreateMonthlyBill` ใน `application/create_monthly_bill.py` ผู้เรียกต้องส่งข้อมูลห้อง รอบบิล ราคา และค่ามิเตอร์เข้ามาเอง; use case คืน `Bill` แต่ไม่ได้อ่านข้อมูลจาก Repository หรือบันทึกบิล

### ขั้นตอนการทำงาน (Workflow)
1. **ตรวจสอบรอบบิล**: รับ `BillingPeriod` หรือ string รูปแบบ `YYYY-MM` (เดือนต้องอยู่ระหว่าง `01` ถึง `12`)
2. **ตรวจข้อมูลมิเตอร์**: ต้องส่งมิเตอร์น้ำและไฟเป็น tuple ที่มีค่า 2 ค่า (ค่าปัจจุบัน, ค่าก่อนหน้า); หากไม่ส่งหรือ tuple มีจำนวนค่าไม่เท่ากับ 2 จะเกิด `MissingRequiredDataError`
3. **เลือกประเภทรายการ**: ใช้ `BillingRules`; ค่าเช่าคิดเฉพาะผู้เช่า, ค่าน้ำและค่าไฟคิดทุกห้อง, ค่าเคเบิลไม่คิดกับเจ้าของและห้องที่ยกเว้น, ค่าที่จอดรถไม่คิดกับเจ้าของและคิดเมื่อห้องมีที่จอดรถ
4. **คำนวณ**: ค่าน้ำและค่าไฟใช้ผลต่างระหว่างค่าปัจจุบันกับค่าก่อนหน้าคูณอัตราจาก `BuildingPricing`; หากค่าปัจจุบันน้อยกว่าค่าก่อนหน้าจะเกิด `DecreasingUnitError`; มูลค่าเงินใช้ `Decimal`
5. **สร้างหรือคำนวณบิลเดิมใหม่**: สร้าง `Bill` ใหม่ หรือเมื่อตั้ง `existing_bill` จะล้างรายการเดิมก่อนคำนวณรายการใหม่
6. **คืนผลลัพธ์**: `Bill.total` รวมยอดจากรายการทั้งหมด; ผู้เรียกเป็นผู้ตัดสินใจว่าจะจัดเก็บบิลอย่างไร

## 2. องค์ประกอบการคำนวณบิล (Bill Items)

- **ค่าเช่าห้อง (Rent)**: คิดเฉพาะผู้เช่า ตามอัตราค่าเช่าประจำห้อง (`room.rent_rate`)
- **ค่าน้ำ (Water)**: คำนวณจาก `(Current Meter - Previous Meter) * Water Rate`
- **ค่าไฟ (Electricity)**: คำนวณจาก `(Current Meter - Previous Meter) * Electricity Rate`
- **ค่าเคเบิล (Cable)**: ไม่คิดกับเจ้าของหรือห้องที่ตั้ง `cable_exempt`; ราคาอ้างอิงจาก `building_pricing.cable_price`
- **ค่าที่จอดรถ (Parking)**: คิดเมื่อห้องมีที่จอดรถและผู้พักไม่ใช่เจ้าของ; ราคาอ้างอิงจาก `building_pricing.parking_price`
